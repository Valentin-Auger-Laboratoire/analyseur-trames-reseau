## Français

### Ce que fait l'outil
Analyseur de captures réseau dans le navigateur, sur le principe de Wireshark, en HTML / CSS / JavaScript pur (aucune bibliothèque, aucun serveur). Le fichier est lu en local : **rien n'est envoyé sur Internet**.

- **Lecture des fichiers** `.pcap` (µs et ns, les deux boutismes) et `.pcapng` (blocs SHB, IDB avec `if_tsresol`, EPB, SPB) produits par Wireshark, tcpdump ou Scapy.
- **Liste des paquets** : numéro, temps, source, destination, protocole, longueur, résumé ; lignes marquées pour les anomalies.
- **Détail par couches** (arbre dépliable) et **vue hexadécimale** : cliquer un champ surligne ses octets.
- **Protocoles décodés** : Ethernet II, 802.1Q (VLAN), ARP, IPv4, IPv6, ICMP, TCP (options), UDP, DNS (avec compression des noms), HTTP, TLS (ClientHello : SNI), FTP et Telnet (commandes).
- **Sommes de contrôle** vérifiées : en-tête IPv4, TCP et UDP (pseudo-en-tête).
- **Analyse automatique** : identifiants en clair (HTTP Basic, FTP USER/PASS), retransmissions TCP, balayage de ports (≥ 10 ports d'une même source), réponses DNS NXDOMAIN, sommes de contrôle fausses, poignées de main TCP, connexions refusées (RST), SYN sans réponse ; répartition par protocole et conversations IP.
- **Filtres d'affichage** proches de Wireshark : `tcp`, `dns`, `arp`, `tls`…, `ip.addr`, `ip.src`, `ip.dst`, `tcp.port`, `udp.port`, `port`, `tcp.stream`, `vlan`, `frame.number`, avec `==`, `!=`, `and`, `or`, `not` et parenthèses. Exemple : `tcp.port == 443 and not tls`.

**Capture d'exemple** (64 trames, générée par `exemple.js`, téléchargeable en `.pcap`) : scénario **fictif** inspiré du [PoC réseau de téléradiologie](https://github.com/Valentin-Auger-Laboratoire/poc-reseau-teleradiologie) : ARP sur VLAN 10, ping, DNS, HTTPS avec SNI, connexion HTTP avec identifiants Basic en clair, retransmission, FTP, NXDOMAIN et balayage de 16 ports. Les identifiants sont des valeurs de démonstration.

### Fichiers
| Fichier | Rôle |
|---|---|
| `pcap.js` | Lecture pcap/pcapng, dissection, analyse, filtres (aucune dépendance au navigateur, testable avec Node) |
| `exemple.js` | Génération de la capture d'exemple (sommes de contrôle valides) |
| `index.html` | Interface, bilingue FR / EN |
| `tests/test.js` | Tests |
| `tests/donnees/` | Captures de référence écrites par Scapy (`ref.pcap`, `ref.pcapng`) et valeurs attendues (`ref.json`) |

### Lancer les tests
```bash
node tests/test.js
```
- Somme de contrôle Internet sur l'exemple classique de la RFC 1071.
- **300 paquets aléatoires écrits par Scapy** (outil indépendant), en pcap et en pcapng : adresses, ports, numéros de séquence, réponses DNS, VLAN et sommes de contrôle doivent concorder.
- Capture d'exemple : contenu, alertes attendues, détection d'une trame altérée.
- Filtres : nombres de paquets attendus et rejet des filtres invalides.

### Limites
- Seul un sous-ensemble de protocoles est décodé (pas de QUIC, SMB, DHCP détaillé…), sans réassemblage des flux TCP ni déchiffrement TLS.
- Les noms des champs dans le détail sont en français.
- Gros fichiers : tout est chargé en mémoire dans le navigateur.

### Utiliser en local
Ouvrir `index.html` dans un navigateur.

## English

### What the tool does
Browser-based network capture analyser, in the spirit of Wireshark, in plain HTML / CSS / JavaScript (no library, no server). Files are read locally: **nothing is sent over the Internet**.

- **Reads** `.pcap` (µs and ns, both byte orders) and `.pcapng` (SHB, IDB with `if_tsresol`, EPB, SPB blocks) from Wireshark, tcpdump or Scapy.
- **Packet list** with flagged rows for anomalies.
- **Layered detail tree** and **hex view**: clicking a field highlights its bytes.
- **Decoded protocols**: Ethernet II, 802.1Q (VLAN), ARP, IPv4, IPv6, ICMP, TCP (options), UDP, DNS (name compression), HTTP, TLS (ClientHello SNI), FTP and Telnet commands.
- **Checksums** verified: IPv4 header, TCP and UDP (pseudo-header).
- **Automatic analysis**: cleartext credentials (HTTP Basic, FTP USER/PASS), TCP retransmissions, port scans (≥ 10 ports from one source), DNS NXDOMAIN, bad checksums, TCP handshakes, refused connections (RST), unanswered SYNs; protocol breakdown and IP conversations.
- **Display filters** close to Wireshark's: `tcp`, `dns`, `arp`, `tls`…, `ip.addr`, `ip.src`, `ip.dst`, `tcp.port`, `udp.port`, `port`, `tcp.stream`, `vlan`, `frame.number`, with `==`, `!=`, `and`, `or`, `not` and parentheses.

**Sample capture** (64 frames, generated by `exemple.js`, downloadable as `.pcap`): a **fictional** scenario based on the [teleradiology network PoC](https://github.com/Valentin-Auger-Laboratoire/poc-reseau-teleradiologie). Credentials are demo values.

### Tests
```bash
node tests/test.js
```
RFC 1071 checksum example; **300 random packets written by Scapy** (an independent tool) in pcap and pcapng, whose addresses, ports, sequence numbers, DNS answers, VLANs and checksums must match; sample capture content and alerts; tampered frame detection; display filters.

### Limits
- Only a subset of protocols is decoded; no TCP stream reassembly, no TLS decryption.
- Field names in the detail tree are in French.
- Large files are fully loaded in browser memory.
